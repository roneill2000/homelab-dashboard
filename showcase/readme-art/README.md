# README artwork

`banners.py` draws the README banner (`../banner@2x.png`, factor 2) and the 1280x640 social preview (`../banner.png`, factor 1);
`dash-gallery.py` lays out `../gallery-desktop.png` from the showcase screenshots at native resolution. Shared with the
[Android repo](https://github.com/roneill2000/homelab-android/tree/main/tools/readme-art), which holds the usage notes.
