01 · Overview

What needs attention, and the buttons you use most

A status line at the top says “All clear” or lists what needs attention, and each item opens its page. Below it: power for the gaming PC, a DNS pause, an update check, and a one-line box for asking the local Qwen model.

One tap from the phoneWake or sleep the gaming PC, pause ad blocking, or check for updates without leaving the first screen.
Safe buttonsEvery action confirms first with a button named after what it does, and only works from the dashboard itself.
Missing data stays missingEach reading has a timestamp. If a source stops answering, the tile shows “—” instead of zero.

02 · Storage & GPU

Disk activity and the Arc A310 GPU

Read and write speed, busy time and latency for each disk, taken from the Linux kernel’s counters. The Arc A310 panel, now on the Local AI page, shows render, compute and VRAM use.

Cache forecastEstimates when the Unraid cache will fill and starts the mover before it does.
Shares remount themselvesA timer checks network shares every two minutes and remounts any that stop responding.
Gaps in the chartAfter a reboot the chart shows a gap. It doesn’t fill in made-up numbers.

03 · Local AI

AI models that run at home

Three models run on an RTX 5070 Ti through llama.cpp, and the page shows whether the gaming PC is on, with Wake and Sleep buttons. A small Qwen model on the Arc A310 answers questions about the homelab and shows the data it used.

04 · Updates

Updates run one guest at a time

Each Proxmox container gets a snapshot before apt upgrade. Docker apps update through Unraid’s own updater. The run stops at the first failure and shows the rollback command.
