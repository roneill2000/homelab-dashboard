## How to verify (do this after every change)

```
npm run build
npm run check          # 9-script Playwright gate; must end "ALL CHECKS OK"; retries a failed script once
node screenshots.mjs <label>   # needs `python3 preview.py` running; writes .preview/shots/<label>/
```
- `run-checks.mjs` refuses to run if port 8799 is busy: `pkill -f "preview\.py"` first. Do not use a plain `pkill -f "python3 preview.py"` inside an `ssh ... '...'` command; it matches and kills the ssh session itself.
- Checks fall back to Playwright's bundled Chromium when Google Chrome is absent (`PW_NO_CHROME`).
- Gate = accessibility, activity, cache-forecast, content, nightly, qwen, responsive, ui-smoke, updates. `npm run check:all` also runs ai, coverage, gpu, log, log-groups, which fail on stale live-data expectations (open item 3).
- Never weaken a check to make it pass. The checks pin these contracts: exactly one `.sidebar` and one `.theme-toggle` per window class; nav buttons named like "All services 28" and "Updates N pending"; "Open navigation" is the 2nd tab stop on phones; `.topbar` buttons >= 44px; `.command-results a`; no horizontal scroll at 360-3440px; pin buttons named "Pin X"/"Unpin X".
- Resize races bit us three times (search bar, progress SVG, grid columns): anything whose width comes from React state after a resize must be clipped or hidden by CSS breakpoints so the first frame cannot overflow.

## Gotchas learned today

- material-web `latest` and `v0_192` disagree (state layers 0.10 vs 0.12, button padding 16 vs 24, nav bar 64 vs 80). Use `latest`; it is what the audits judged against.
- `customColor()` accents (teal, green, cyan, blue, indigo, purple, pink, orange, amber) are harmonised to the seed; they are not part of any Google spec.
- The live server re-renders every few seconds; the local preview does not. Test interactive behaviour against `DASHBOARD_URL=http://192.168.0.2/` too.
- `deploy.py` executes `backend_patch.py` remotely with `exec`, so patches cannot read sibling files.
